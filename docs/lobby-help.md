# 大厅与房间

在大厅选择 **1v1** 或 **2v2**，点击“开始单人对战”即可进入。单人模式不需要网络：1v1 面对一位电脑对手；2v2 与一位电脑盟友合作。

点击“多人房间”展开联网面板。填写昵称，使用随游戏提供的服务器地址，或者输入自己的兼容房间服务器地址。在“房间规模”中选择 **1v1 · 双方对决** 或 **2v2 · 四人组队**，然后点击“创建房间”。房主可以将八位邀请码复制给朋友；其他玩家输入邀请码后加入。房间创建后模式固定，离开房间后可以重新选择。

**2v2 默认席位 1、2 为同队，席位 3、4 为另一队**。房间上方会直接显示联盟与席位对应关系。房主可以用每行的联盟菜单调整队伍，开局时双方人数必须相同。

房主可直接点击空席上的“添加电脑”，或点击“一键补齐空位为电脑”。补齐操作只处理空位，不会替换真人。电脑席位上的“移除电脑”可重新腾出位置，让朋友加入。席位修改等待服务器确认时，相关按钮会暂时禁用，避免连续点击重复发送。

**一位房主加三位电脑就能开始 2v2，无需再等待真人**。全部席位需要有玩家或电脑，加入的真人都准备就绪后，房主点击“开始 2v2 对战”。房主默认就绪，电脑自动就绪；房间设置变化时，其他真人需要重新准备。

连接失败会在面板底部说明原因。可以重试，或者直接开始单人对战。昵称和公开服务器地址会保存在本机；大厅不会保存或显示服务器管理凭据。

主菜单的“设置”可以调整显示、声音、镜头和热键。战斗中按 F5 打开战场菜单，也能进入同一设置界面。窗口模式、分辨率、垂直同步与帧率上限会保存到本机；更改显示设置后，15秒内点击“保留设置”，否则恢复先前画面。声音仅包含音效，没有背景音乐。

热键页提供35项操作的独立绑定。生产、建造与研究使用当前面板的槽位：默认从左至右 Q、W、E、R、T、Y，大本营的 Q 训练农民，兵营的 Q/W/E 训练剑士、弓手、骑士。按钮角落、帮助和编队提示会跟随绑定更新。完整操作见[玩家说明](windows-readme.txt)。

单机按 F5 暂停/继续。联机 F5 的全局暂停由房主控制，普通玩家只打开或关闭本地菜单；Esc用于取消指派或队尾生产/研究。双方的颜色按每个观看者区分：自己蓝色、队友黄色、敌人红色；颜色只影响辨识，不改变单位所有权。

大厅采用 Godot 原生场景节点，主菜单、多人房间与设置各有独立入口。模型背景和界面使用与战场一致的石材、木材与暖色调；大厅和战斗共用玩家选择的显示与输入设置。
