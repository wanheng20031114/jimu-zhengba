# 大厅与房间

在大厅选择 **1v1** 或 **2v2**，点击“开始单人对战”即可进入。单人模式不需要网络：1v1 面对一位电脑对手；2v2 与一位电脑盟友合作。

点击“多人房间”展开联网面板。填写昵称，使用随游戏提供的服务器地址，或者输入自己的兼容房间服务器地址。房主点击“创建房间”，将八位邀请码复制给朋友；其他玩家输入邀请码后加入。

房主可以把空位切换为电脑，并调整每个席位的联盟。已经加入的真人玩家不能被替换成电脑。双方人数必须相同，所有真人玩家准备就绪后才能开始。房间设置有变化时，其他玩家需要重新准备。

连接失败会在面板底部说明原因。可以重试，或者直接开始单人对战。昵称和公开服务器地址会保存在本机；大厅不会保存或显示服务器管理凭据。

大厅全部采用 Godot 原生场景节点。实时背景展示兵营、军工厂和学院；界面进入时淡入，展开房间面板时短暂过渡，背景镜头缓慢变化。大厅限制为 60 FPS，离开后恢复进入前的帧率限制。
