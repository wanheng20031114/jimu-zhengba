# 积木争霸 0.10.0 交付记录

本版修复小整数伤害下的过长交战，并加入炮射程、单位恢复和阶梯塔价。Windows正式包已生成，上海独立中继已升级至协议9。所有真人需更新同版，旧0.9.0不可混入。

## 数值和玩法

- 骑士1人口；普通兵生命沿用，投石140生命、炮180生命。剑士镜像50刀→17刀。无科技全部移动单位互打最多40击；五类军事单位全部16种攻防等级差均不超过40击。
- 剑士反骑6刀，骑士切弓5刀，弓手打剑士9箭；弓手仍需射程先手与前排，不能把贴身换血称为优势。
- 投石半径3全范围同伤，无友伤，剑士5击、弓手4击；炮单体，对建筑+150、攻城器+12，打投石4炮、同款5炮。
- 塔1000生命、射程13，对三类常规兵各防御等级需6至10次命中。累计付费建造价格150/185/225/255/280/270，此后270；赠塔不计，取消/摧毁不回退。退款读取工地实际支付金额。
- 炮基础射程13，学院“加长炮管”240金/30秒升至14；“战地休整”100金/20秒，全部己方可移动单位10秒未受伤后每满1秒回复1生命，首次回复在最后受伤后第11秒。
- 全移动单位视野增加1。学院7条路线分页，图鉴同步25项内容，本人私有科技/塔价与可见单位有效射程通过房主权威快照同步。

完整6×6默认与同级表、36张非对称科技表、建筑伤害和超过40击的例外，见[完整数值报告](../report/balance-0.10.0.md)。建筑重甲和农民攻击满科技军队仍有长对位，报告明确保留原因与限制。
