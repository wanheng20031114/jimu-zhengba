## 选择操作

Ctrl＋左键单击己方单位，与原有双击使用同一筛选逻辑：全选当前相机视野内同种己方部队。Ctrl＋Shift＋左键追加同种部队；不会选入屏幕外、盟友或敌人的部队。Ctrl拖动仍执行框选，Ctrl＋数字覆盖编队、Shift＋数字追加编队保持原行为。F1操作说明与随包玩家说明同步更新。
