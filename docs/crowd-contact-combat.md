# 大规模交战推挤与停攻修复

2026-09-10，Godot 4.6.3。

## 行为调整

- 所有玩家和电脑的移动单位使用相同的原生 RVO 避让优先级，取消骑兵、投石车和火炮原有的高优先级。
- 单位停下攻击、坚守或工作时，将原生避让最大速度设为零，让移动部队绕行；重新产生移动意图后恢复正常速度。站稳状态独立于动画状态管理。
- 待命或攻击移动时，如果原自动目标已超出射程，允许改选已经在射程内的敌人，避免被前排挡住后持续追逐旧目标。没有合适目标则保留原目标；明确攻击命令和正在进行的攻击前摇保持锁定。
- 主机权威模拟统一应用这些规则，客户端继续复制结果。脱战回血科技未调整。

## 验证

在不包含工作区导航原型的干净 `a065e2a` 副本上，对照应用本次补丁前后的结果：

| 检查 | 结果 |
| --- | --- |
| 新增拥挤交战回归 | 修复前 152 项中 42 项失败；修复后 152/152 通过 |
| 追击及攻击时序，30/60 TPS | 466/466 通过 |
| 多人实体复制 | 124/124 通过 |

拥挤测试覆盖全部 8 个玩家席位的 24 对 24 剑士与骑兵交战、友军后排挤压坚守队列、绕过零散待命单位、坚守后恢复移动，以及自动目标切换和明确攻击锁定。保留真实物理、原生 RVO、攻击计时器和伤害结算，仅增加测试单位生命值以维持观察时间。

修复后坚守队列最大位移为 0 米；干净副本中，实际有敌人在射程内时，剑士最长累计待命中时间为 1.47 秒、骑兵为 1.10 秒。离开射程只暂停累计，实际命中才清零；同时检查接敌人数、双方总命中数和攻击成功率，避免把后排正常等待误判为停攻。
