# 0.7.0 交付记录

2026-09-10；Godot 4.6.3 Windows x64 / Forward+。源码阶段提交为 `ec91a45`、`1ef6113`，均已推送公开仓库。Windows 包由 `1ef6113` 导出，后续验收记录、测试日志命名修正与测试 UID 不改变运行资源。

## 玩家可见变化

- 普通军事单位训练 6／8／10 秒，攻城器 20 秒，农民 10 秒。训练与科技排队在生产栏上方逐格显示，可逐项取消；多建筑汇总分页，人口入队即预留。
- 当前生产、建造与研究面板默认 Q／W／E／R／T／Y，按钮角标与重绑实时同步。F2 选择全部己方军事单位；建筑支持编队、追加及类别切换。
- Shift 连续移动、攻击、采矿、施工与坚守；选中单位时显示当前与后续最多八项任务的地面旗帜和连线。Delete 销毁所选己方资产。
- 生产沿建筑整个周边寻找出口，优先朝集结点的直线方向。大本营集结到矿脉后，新农民自动采矿。训练完成而出口全堵时保留完成状态。
- 矿工改为每 3 秒采 4 金币，自然收入保留每秒 1。3／6／10 名活跃矿工对应总收入 5／9／14.33 金币每秒。
- 修正自然障碍的多余碰撞占地，建筑按实际占地允许贴邻和封路；大本营两座前塔提高，塔顶完整高于当地屋檐。
- 清除多余移动尘土，修正复用特效误启动粒子；强化己方蓝、盟友黄、敌方红的模型色区，区分兵营、军工厂与学院外形。
- 生成原生透明背景的剑／盾科技图标；使用七种 SVG 上下文鼠标提示攻击、采矿、施工、移动与集结。
- 完整主菜单及战场菜单，设置覆盖显示模式、分辨率、VSync、帧率上限、音量、镜头和 34 项热键。显示变更有 15 秒自动恢复；F5 暂停，联机由房主控制；鼠标越过仍聚焦的窗口边缘可以继续移动视角。

规则细节见 [玩家说明](windows-readme.txt)、[生产与研究](production-queues.md)、[经济与建筑出场](rts-economy-placement.md)、[设置](settings-and-menus.md)、[操作反馈](world-order-feedback.md)。

## 当前性能与边界

RTX 3080、1600×900、Vulkan，辅助功能检查结束后独立进行三个阶段的源码实际渲染采样；每阶段预热后采样约 15 秒，保留用户编辑器及其他桌面应用。不是无头 FPS，也不是发布 EXE 的性能测量。

| 2v2 场景 | 显示帧 P95／P99 | 逻辑步 P95／P99 |
|---|---:|---:|
| 标准混编，208 人开始 | 15.81／24.23 ms | 8.81／9.51 ms |
| 极限密集交战，280 人开始 | 31.92／34.83 ms | 12.71／14.17 ms |
| 满员行军，280 人 | 15.18／23.49 ms | 8.30／11.50 ms |

标准混编 P95 低于 16.67 ms，但 P99 仍有波动；280 人极限混战不能稳定 60 FPS。全部三阶段逻辑 P95 低于 33.33 ms。正式画质未降低；测试夹具在场景启动后明确关闭其自身限帧和 VSync，避免新设置加载覆盖测量条件。详细负载、画质与后台应用条件见 [0.7.0 性能报告](performance-0.7.0.md)。

结束前使用 CIM 核实本项目 `--headless`／`--check-only`、发布验收、截图及性能辅助进程数量均为 0，仅保留用户原有 Godot 编辑器 PID 19228。上海已交付的生产中继继续运行。用户原有 `project.godot`、`default_bus_layout.tres` 工作区修改未纳入本轮提交。
