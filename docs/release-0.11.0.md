# 积木争霸 0.11.0 交付记录

本版更新已确认的视野、训练时间和加农炮伤害，优化 CPU 导航、迷雾、动画及表现资源复用。Windows 正式包与上海中继均为 0.11.0、协议 9，联机玩家需要使用同版。**896 单位极限性能仍未达标。**

## 实施内容

- 导航网格合并相邻可走区域，复用障碍前缀和。近距离追击先检查完整身体扫掠区域；空矩形为常数时间，斜线旁有障碍时按有限格行细查，真正受阻则保留原生 A*、RVO 与碰撞。没有减少权威模拟频率。
- 迷雾改为逐行区间累加，避免重复填写大量重叠视野圆。小地图地形读取同一份可见性纹理；单位和建筑标记继续过滤当前视野。
- 六种模型用原生可见性事件暂停离屏动画回调，保留动画资源与缓存。出手、联网状态和回到画面时补齐姿态；不暂停游戏逻辑、采矿或伤害计时。
- 弹丸飞行和视觉池分离，预热 64 个视觉对象，扩容至最多 256 个；视觉达到上限不会丢失伤害。128 个特效对象复用，密集小命中效果按屏幕区域合并，重要爆炸和命令反馈保持优先。声音沿用有界声部和共享预载音源。
- 修复被直接释放的攻击目标使 Shift 后续指令延迟一个逻辑步的问题；重复攻击仍不重置冷却或前摇。

## 性能结果与限制

| 原生 4v4 场景 | 平均 FPS | 实际 TPS | 显示帧 P95 / P99 |
| --- | ---: | ---: | ---: |
| 272 单位标准混编 | 130.80 | 30.00 | 14.896 / 17.696 毫秒 |
| 896 单位研究后满人口 | 3.31 | 25.39 | 346.321 / 347.524 毫秒 |

RTX 3080、1600×900、Godot 4.6.3 官方发布模板，使用生产场景和临时测量入口；每阶段预热 6 秒、采样 15 秒。保留用户编辑器和当时运行的游戏，属于共享工作站测量。旧版是编辑器引擎样本，不能把两版全部差额都归因于代码。272 单位 P99 仍超过 16.7 毫秒，也不宣称稳定锁定 60 FPS。

896 单位的主要瓶颈已定位为 CPU 节点回调及导航阶段的移动回调，超预算导致连续补算逻辑帧。关闭 3D 的诊断显著降低 GPU 时间，却没有改善早期约 1.7 FPS 的结果；Jolt 服务器纯步进并非主要开销。原生分段计时、对照实验、已撤回的无收益方案及后续边界见 [性能报告](../report/performance-0.11.0.md)。
