# 0.7.1：兵种调整、集结反馈与取消操作

2026-09-10；Godot 4.6.3 / Windows x64。游戏版本 `0.7.1`、协议 `4`；同一房间的玩家需使用相同版本。

## 对局与操作

弓箭手基础攻击 **14→12**，对骑兵附伤仍为 +12，攻速、造价与训练时间保持现行值。满血无科技时，对骑士伤害为 22、需要 6 箭；对剑士伤害为 8、需要 13 箭。骑士视野 **12→15**，比弓手的 13 更远，有利于提前侦察和迂回。完整计算与实际箭矢/战争迷雾验证见 [平衡说明](ranged-balance.md)。

选中己方生产建筑时，地面显示更大的集结旗和建筑至目标的连线；大本营采矿集结为金色，普通集结为蓝色。支持多选、工地和远端客户端；多个建筑共用目的地时合并旗帜，各楼连线保留。只读取所属玩家已有的私有集结状态，不增加敌军信息。原生 MultiMesh 复用与单位 Shift 路线共存，详见 [世界操作反馈](world-order-feedback.md)。

多人创建面板提供明确的 1v1／2v2 选择，空席直接显示“添加电脑”，电脑席位显示“移除电脑”，另有“一键补齐空位为电脑”。已加入真人不能被覆盖，联盟摘要明确列出双方席位。2v2 可以一名房主加三个 Bot 开局；所有席位与准备规则由中继验证。[房间操作](lobby-help.md)

**Esc 默认取消指派或所选生产类别的队尾项目**，每次取消一个。建造预览、攻击指派和帮助面板优先退出，随后才是训练／研究队列。多选同类建筑时先处理项目数最多的队列，平局按稳定建筑编号选择；Tab 切换当前建筑类别。空队列不暂停游戏，也不会删除建筑或单位。点击格子仍可取消指定项目。

队尾选择由房主在固定逻辑步执行，快速连续按两次会处理两项，不依赖尚未更新的客户端队列快照；仍经过所有权、命令序号和退款规则验证。研究取消沿用既有前置依赖处理，预留人口及时释放。

**F5 默认统一负责暂停、战场菜单与继续**，包括设置界面。单机暂停整个对局；联机全局暂停只有房主可以操作，普通玩家的 F5 只打开／关闭本地菜单。设置中的 F5 关闭设置后执行同一暂停入口，未应用的草稿丢弃，未确认的显示设置恢复；捕获新热键时优先处理按键绑定，不会意外恢复游戏。

“取消指派 / 队尾生产或研究”和“暂停 / 战场菜单 / 继续”都在原生热键设置中，共 **35 项**。旧默认 F5/P 组合自动迁移为 F5，其他自定义按键、音量和显示偏好保留。Esc仅允许绑定取消操作，设置界面中的 Esc 仍用于返回；F12 继续保留单机调试。
