灰烬王国 · 中世纪乱斗 0.5.0

将整个压缩包解压到本地，双击 AshenCrown.exe 开始游戏。
AshenCrown.pck 必须与程序放在同一文件夹中。
需要 Windows x64、支持 Vulkan 的显卡和可用的中文系统字体。

目标：摧毁四座敌方军事建筑，并保卫王国大本营。
大本营已默认选中。Q/E/R/T/Y 即时招募剑士、弓箭手、骑士、投石车、加农炮。
U 即时招募农民，每人 50 金币；开局已有 2 名农民。
金币每秒自动增加 1；F12 调试获得 100 金币。

选中农民后右键矿脉，抵达矿边开始采集，头顶显示进度条。
每名农民每完成 3 秒工作，金币立即增加 3，无需运回大本营；矿脉不会耗尽。
移动或 S 停止可中断采矿，未完成周期不入账；重复点击同一矿脉不会重置进度。
选中大本营后右键矿脉，新招募的农民会自动前往采集。

选中农民按 V 显示防御塔预览，在空地左键放置，立即花费 100 金币。
农民抵达后累计施工 20 秒；每座塔只允许一名施工者，多人不会加速。
工人离开或死亡后保留工地进度，可用其他农民右键工地接手。
工地可以被敌人破坏；塔完成后自动射击附近敌人，不能进驻单位。
Shift + 左键可连续放置多座塔；右键或 Esc 退出预览。
Shift + 右键可将移动、采矿、施工混合加入任务队列。
有后续任务时，采矿完成当前的 3 秒周期后执行下一项；最后的采矿任务持续采集。
选择未完成工地按 Delete 取消，按未完成比例退款并向下取整。
普通 Delete 不拆除完成塔。选择自家已完成塔按 Ctrl + Delete 拆除，无金币返还。

左键选择 / 拖动框选，Shift 追加选择，双击选择视野内同类单位。
右键移动、攻击、采矿或接手工地，Shift + 右键追加任务。
A + 左键攻击前进，S 停止，H 坚守。
军事单位待命时会主动追击附近敌人；H 坚守只攻击射程内敌人，不追击。
Ctrl + 数字建立/覆盖编队，Shift + 数字添加所选部队，数字召回，双按数字定位。
鼠标移到窗口或全屏画面边缘移动镜头；四角支持斜向移动。
中键拖动或方向键也可移动镜头；滚轮缩放。
B 选中大本营，G 选中全军（不含农民），.（句点）轮选空闲农民。
空格定位所选部队。
选中大本营后右键地面设置集结点。
F1 操作说明，Esc 暂停/继续，F11 全屏，M 静音，F10 隐藏界面。
Esc 暂停界面提供音效音量滑块。当前版本不播放背景音乐。
连续右键攻击同一目标不会重新开始攻击前摇；改攻其他目标仍立即响应。
战场采用 45° 正交镜头，自然岩石与树木取代原有无功能房屋。

音效包含 54 个 WAV 变体、22 类事件，覆盖攻击、发射、命中、移动、死亡、倒塌及操作反馈。
农民采矿与建造、塔的弩箭攻击使用同一音效体系，保持响度一致。
38 个固定声部结合距离衰减、同类限流、战斗轻压缩与总线限峰，控制大规模交战时的响度。
