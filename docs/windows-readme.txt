灰烬王国 · 中世纪乱斗 0.6.0

解压完整 windows 文件夹，双击 AshenCrown.exe。EXE 与 PCK 必须留在同一目录。
单人默认 1v1 对 Bot，也可选择 2v2，与盟友 Bot 并肩作战。
联机：创建房间，将邀请码告诉朋友；全员准备后由房主开始。
游戏通过上海服务器 UDP 24571 加密中继连接，无需房主端口转发。

开局：大本营、3 农民、320 金币。农民自动采矿，每3秒+3；自然收入每秒+1。
大本营只训练农民，50 金币、10 秒；农民含队列最多10人，每矿最多6人同时工作。
选择农民建兵营，生产剑士/弓手/骑士；军工厂生产投石/炮，军事单位即时出场。
军事人口上限60，剑士/弓手1、骑士2、攻城器3。学院研究全军攻防，三级总加成1/2/4。
右上分别显示军事人口与农民人数，训练中的农民已计入上限；将鼠标移到农民人数可查看明细。
农民留在矿边持续采集，无需返程；兵营建成后可建军工厂与学院，选中建筑查看生产和研究选项。
防御塔100金币、20秒施工，自动攻击，无驻军。兵营150，军工250，学院200，大本营重建400。
摧毁敌队全部军事建筑和工地获胜。失去大本营仍可继续战斗和重建。

操作：
左键选择、拖动框选；右键移动/攻击/采矿/接手施工/建筑集结点。
Shift+右键追加任务；按住Shift连续放置建筑。
A攻击前进，S停止，H坚守；Ctrl+数字覆盖编队，Shift+数字追加，数字召回，双按定位。
中键拖动、方向键或鼠标移到屏幕边缘平移；滚轮缩放，空格定位选中部队。
B选大本营，F2或G选全部己方战斗单位，句点选择空闲农民；V快速建防御塔。
选对应建筑后 Q/E/R 招剑/弓/骑，T/Y招投石/炮，U训练农民。
Delete取消工地，Ctrl+Delete拆除已完工自家塔；训练与研究显示在生产栏上方的小格子中，点击指定格子取消并全额退款。
F1操作说明，F11全屏，M静音，F10隐藏界面。
Esc打开菜单：单机暂停，联机仅打开本地菜单；P由房主统一暂停/继续。
F12仅单机增加100金币。没有背景音乐，音效音量可在菜单调整。

断线：普通玩家10秒后由Bot接管，120秒内可重连取回；房主等待30秒，超时中断，不迁移房主。
禁止直接控制盟友，队伍共享视野。战争迷雾外不会显示敌军实时位置、血条或声音。
所选己方军队显示科技升级后的属性；盟友与敌军属性标记为“基础”，不代表其实际科技等级。

使用独立显卡与最新显卡驱动。默认1600x900，Forward+ Vulkan，30TPS模拟与显示插值。
