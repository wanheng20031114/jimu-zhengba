积木争霸 0.11.0

解压完整 windows 文件夹，双击 积木争霸.exe。EXE 与 PCK 必须留在同一目录。
主菜单进入单人对战后选择 1v1、2v2、3v3、4v4、2v2v2 或八人乱战；单人其余席位由 Bot 补齐。
联机：进入多人大厅，选择模式创建房间，分享八位邀请码；真人准备后由房主开始。所有人需使用 0.11.0（协议9），不能与旧版混用。
4v4 每队最多四人，支持4v2等不等人数开局；可保留空位，至少两个阵营实际参战即可。乱战最多8人、每人独立阵营，也可少于8人开始。
房主可在空席添加或移除电脑，或主动补齐全部空位；空位不会自动参战、不生成建筑与金币。
调整队伍后，出生位置随阵营排列，队友相邻。自己蓝色、队友黄色、敌人红色，仅同队共享视野。
游戏通过上海服务器 UDP 24571 加密中继连接，无需房主端口转发。
图鉴共25项：6种单位、5种建筑、14项科技，直接读取当前游戏数值；拖动预览可旋转模型，防御塔还会说明阶梯造价与退款规则。
更名后自动迁移旧版设置、热键和房间偏好，已有新版设置不会被覆盖。

开局：大本营、左侧出生矿旁的一座已完工弓箭塔、3 农民、320 金币。开局塔免费，所有模式中每位真人和Bot都有一座，1000满血、自动防御；仍需摧毁敌方开局塔才能完成清建筑胜利。农民自动采矿，每人每3秒+4；自然收入每秒+1。
农民留在矿边采集，无需运输；每矿最多6人工作，额外农民等待空位，矿脉不耗尽。
大本营只训练农民，50金币、10秒，存活加排队基础最多10人；学院研究扩展后最多12人。
兵营训练剑士45金币/6秒、弓手60金币/7秒、骑士80金币/8秒。
军工厂训练投石车200金币/20秒、加农炮250金币/20秒。
投石车140生命、近甲0/远甲2、射程13、最小射程3、视野14、基础范围伤害18，对剑士+6、建筑+50；半径3内均为满伤，无边缘衰减、无友军伤害，发射后落点固定，可以走位躲避。无科技对剑士24、弓手15、骑士12、投石车16、加农炮16、建筑58，剑士5击、弓手4击；即使攻击III打无防科技，两者也至少4击。
加农炮180生命、近甲0/远甲2、射程13、最小射程2.5、视野14、基础单体伤害40，仅对建筑+100，没有攻城器类别附伤；无科技对建筑130、同款加农炮38，需要5炮摧毁同款；双方同级攻防科技仍需5炮。学院研究“加长炮管”后射程升至14。
两种攻城器近甲固定0，防御科技仅增加其远甲。攻击间隔分别3/3.2秒，加农炮视觉爆炸不造成范围伤害。
骑士120生命，近甲2、远甲6，基础攻击9、对弓手+3、对攻城器+11；无科技对弓手每刀12、5刀击杀，对投石车7刀、加农炮9刀；视野16、攻击间隔1.1秒、人口1。
剑士100生命、45金币，近甲2/远甲0，基础攻击8、对骑兵+14，视野14、1.2秒间隔；弓手60生命、近甲0/远甲3、基础攻击12、无类别加成，射程10、视野14、1.5秒间隔。
无科技且不治疗时，剑士→骑士每刀20、6刀，弓手→剑士每箭12、9箭，骑士→弓手每刀12、5刀；弓手对骑士没有特攻，每箭6、需要20箭。骑兵切弓手、弓手远程压制剑士、剑士对抗骑兵；齐射、接敌距离、包围和相同金币下的数量都会影响实际结果。
农民150生命，双甲0、攻击5、射程0.9、视野9、1.3秒攻击间隔，不享受军事攻防科技。
军事人口基础50，学院可升级至75/100，每级500金币、30秒：剑士/弓手/骑士各占1、攻城器占3；包含排队预留人口，农民使用独立名额。
每座生产建筑队列最多10项。金币入队时支付，训练完成但出口堵塞时保留进度等待出场。
训练与研究在生产栏上方逐格显示，点击任何格子取消并全额退款，超过10格可左右翻页。
生产建筑被毁时丢失其队列且不退款，已预留人口释放。
生产建筑沿四周寻找出口，优先朝集结点方向出场；大本营右键矿脉，新农民出场后会自动采矿。
选中己方生产建筑时显示集结旗和连线，普通集结蓝色、采矿集结金色；支持多选建筑。

选农民后建兵营150金币/15秒；兵营建成后可建军工厂250金币/25秒、学院200金币/20秒。
防御塔20秒施工、1000生命、近甲10/远甲10、射程13（与未升级加农炮相同），基础远程攻击13、对剑士+3、对骑兵+9，1.5秒间隔；无科技对剑士16、弓手10、骑士16。自动攻击，不提供驻军功能。
防御塔付费造价按每名玩家的累计成功放置次数独立计算：第1座150、第2座185、第3座225、第4座255、第5座280、第6座及以后270金币。开局免费塔不计入；取消工地、被敌人摧毁或主动拆除都不会回退造价。
每次成功放置付费工地才推进一次报价；金币不足、非法位置或重复命令不会扣费、不会推进。Shift 连续建造会逐次检查最新价格，建造按钮和预览提示显示下一座报价。
取消工地返还实际支付金额乘以未完成比例，向下取整。例如第2座花185金，施工40%后取消返111金；尚未施工时全退。取消不会退回造价序号，完工建筑拆除不退款，被敌人摧毁也不退款。
大本营重建400金币/30秒，每人同时最多一座（含工地），3000生命、近甲10/远甲10、攻击10、射程10、2秒间隔。兵营/军工厂/学院生命分别1500/1800/1400、双甲均为10；建筑不享受军事攻防科技。
建筑由一名农民施工，多人不加速；右键工地可接手，Shift 可排连续建造任务。
建筑可以紧贴建造或用于封路，但不能重叠实际碰撞占地；堵住全部出口时，训练等待通路恢复。
学院攻防分路线升级：攻击I/II/III总加成+1/+2/+4，防御+1/+2/+3，不逐级累加。攻击每级100/250/500金币、20/35/50秒；防御每级150/300/600金币、25/40/60秒。作用于现有和未来军队，农民与建筑不享受军事攻防；攻城器的近甲始终为0。
实际伤害为基础攻击加攻击科技、对应类别附伤，再减对应护甲和防御科技，最低1点。箭矢、投石和炮弹减远程护甲；类别附伤不会重复叠加。防御图标代表护甲，没有独立的护盾生命条。
一次性“农民上限扩展”：125金币、24秒，研究完成后本玩家农民上限10→12，训练中的农民也计入。研究期间仍为10，不会增加矿脉采集位置。
扩展科技同样支持队列、点击或Esc取消全额退款；学院被毁丢失未完成研究，已完成扩展永久保留。默认学院第三项为E，当前面板顺序变化时以按钮角落提示为准。
采矿效率I/II/III：50/150/300金币，15/25/35秒，总提速10%/20%/30%，不乘算叠加。每次仍得4金币，未升级/I/II/III周期约3/2.727/2.5/2.308秒；当前采集进度保留，自然收入每秒1金不变。
一次性“加长炮管”：240金币、30秒，现有及未来加农炮射程13→14，最小射程2.5不变，其他单位和建筑不受益。
一次性“战地休整”：100金币、20秒，全部己方可移动单位，包括农民与攻城器，连续10秒未受伤后，每满1秒恢复1生命。首次恢复在最后受伤11秒后；再次受伤会重置等待和恢复进度，满血停止，阵亡单位不会复活，建筑不受益。
这两项科技同样由学院研究，适用于本玩家现有与未来单位；支持队列、取消全额退款、跨学院不重复研究。已完成效果不因学院被毁而消失。
追击会更新移动目标的接敌路线；近战在挥砍前摇中继续追步，远程在可完成出手的距离停步瞄准。命中时仍检查真实距离，原有攻击间隔和出手关键帧不变。
每座学院可排6项研究，支持预订后续等级；跨学院不能重复订购相同科技，缺少前置时等待。
取消前置研究时，依赖它的后续研究一并取消退款。学院被毁不退其队列，已完成科技保留。
摧毁某一方全部军事建筑和工地后，该方出局，剩余单位退场；其余阵营继续比赛，最后一方获胜。仅失去大本营、尚存其他军事建筑时可继续战斗并由农民重建。
房主阵营先出局时仍主持比赛，请保持房间开启；房主主动离开会中断比赛。

默认操作（可以在设置中更改）：
左键选择、拖动框选、双击同类选择；Ctrl+左键同样选中当前视野内同种己方部队，Ctrl+Shift+左键追加同种部队。
Shift追加选择；单位和建筑均可编队，Ctrl+数字编队照常使用。
右键移动/攻击/采矿/接手施工/建筑集结点；Shift+右键把任务追加到队尾。
A攻击前进，可用Shift追加；S停止立即清除任务；H坚守，Shift+H可排在已有任务之后。
选中单位时，地面旗帜与连线显示当前目标及最多8项后续任务；鼠标图标会提示攻击、采矿、施工或集结。
Ctrl+数字覆盖编队，Shift+数字追加，数字召回，双按定位；Tab切换混编建筑的生产类别。
当前面板从左至右使用 Q W E R T Y，快捷键标在按钮角落：
  大本营 Q农民；兵营 Q剑士、W弓手、E骑士；军工厂 Q投石车、W加农炮。
  农民 Q兵营、W军工厂、E学院、R防御塔、T大本营；V也可快速放置防御塔。
  学院从Q开始显示下一项可排队科技；项目超过六项时显示“更多科技/返回科技”，也可按该按钮角落的快捷键翻页。相同类别的多选建筑自动分配到可用且队列较短者。
Delete销毁所选己方可移动单位或建筑，完工资产不退款，工地按其实际支付金额退还未完成部分，塔的累计造价不回退。
中键拖动、方向键或鼠标靠近窗口边缘平移；窗口仍有焦点时，鼠标移出窗口仍可边缘移动。
滚轮缩放，空格定位所选对象；B选大本营，F2或G选全部己方战斗单位，句点选空闲农民。
F1操作说明，F11全屏，M静音，F10隐藏界面，F12仅单机增加100金币。
Esc取消当前指派模式；选中生产建筑时每次取消当前类别最长队列的末项（训练或研究），空队列不暂停。
F5打开/关闭战场菜单，单机暂停/继续，联机全局暂停仅房主可以操作；普通客户端只开本地菜单。
设置界面中F5也会返回战斗；正在捕获新热键时优先完成按键绑定。

设置入口：主菜单“设置”，或战斗中 F5 → 设置。
显示：窗口、无边框、全屏，分辨率、垂直同步、帧率上限。
修改显示设置后须在15秒内点击“保留设置”，超时自动恢复，避免不兼容显示模式。
声音：音效音量与静音，没有背景音乐。
镜头：边缘移动开关、镜头移动速度、缩放速度。
热键：35项操作可重新绑定，冲突会提示；应用后按钮角落与帮助立即更新，设置在本机持久保存。

自己蓝色、队友黄色、敌人红色，单位服饰与建筑旗帜、布面、屋顶均有明显的阵营色区。
禁止直接控制盟友，队伍共享视野。战争迷雾外不会显示敌军实时位置、血条或声音。
己方军队显示科技升级后的属性；盟友与敌军标记“基础”，不代表其实际科技等级。
普通玩家断线10秒后由Bot接管，120秒内可重连取回；房主等待30秒，超时中断，不迁移房主。

推荐使用独立显卡及更新后的显卡驱动。Forward+ Vulkan渲染，30TPS权威模拟与显示插值。
0.11.0正式release模板复测：272单位平均130.80 FPS、29.999 TPS，显示帧P95/P99为14.896/17.696毫秒；896单位平均3.31 FPS、25.386 TPS，显示帧P95/P99为346.321/347.524毫秒。八人满人口性能问题仍未解决，大规模混战仍会明显变慢；平均帧率不等于稳定60 FPS。
以上为RTX 3080、1600×900、无帧率上限的短时本地压力样本，保留用户编辑器与游戏，暂停Bot及自然收入，并将生命放大100倍维持人口。与0.10.0编辑器引擎的旧测量条件不同，不能将全部差额归因于代码优化。完整条件、CPU/GPU诊断及原始分布：report/performance-0.11.0.md。
完整数值及全部攻防科技对位表：report/balance-0.11.0.md；本版交付记录：docs/release-0.11.0.md（位于公开仓库）。

遇到异常：在游戏目录双击 COLLECT_DIAGNOSTICS.cmd，会在“文档/积木争霸-诊断”生成本地ZIP。
收集内容包括游戏日志、最近7天相关Windows错误、显卡/系统信息及当前EXE/PCK版本与校验值。
不会自动上传，不修改设置，也不复制内存转储内容。可先查看ZIP，再连同当时的操作步骤手动提供给开发者。
0.7.3起日志即时写入磁盘，并记录启动、对局、退出及每15秒的运行概况，帮助定位意外退出。
