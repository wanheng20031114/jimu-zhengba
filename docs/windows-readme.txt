积木争霸 0.13.0

解压完整 windows 文件夹，双击 积木争霸.exe。EXE 与 PCK 必须来自同一发布包并留在同一目录。
本版同步更新上海 relay 和客户端内容清单，包含当前地图修订以及长矛兵、盾卫、战象、轻骑兵。
所有联机玩家请使用本次完整发布包；旧 0.12.0 包和此前单独导出的包内容指纹不同，无法加入新版服务。
网络协议保持10，网络 Build 保持0.11.0；发行版本为0.13.0。是否兼容还取决于兵种及地图内容指纹。

单人及多人模式：1v1、2v2、3v3、4v4、2v2v2、八人乱战。可以在房间空席添加电脑或保留空位。
上海中继通过 UDP 24571 加密连接，支持同时8个房间、每房最多8名真人，无需房主端口转发。
房主负责战斗模拟，客户端接收状态。普通玩家断线后可在宽限期内重连；房主不会迁移。
自己蓝色、队友黄色、敌人红色。仅同队共享视野，无法控制盟友单位。

兵营单位（金币 / 训练时间）：
剑士 60 / 6秒；盾卫 90 / 10秒；长矛兵 40 / 6秒；弓箭手 60 / 7秒；骑士 80 / 8秒；战象 300 / 30秒；轻骑兵 70 / 7秒。
军工厂：投石车 240 / 20秒；加农炮 255 / 20秒。大本营：农民 50 / 10秒。
盾卫145生命、近甲3/远甲7、移速3.5；战象360生命、26单体近战攻击，属于骑兵；轻骑兵移速6.8、视野20。
长矛兵对骑兵额外20伤害；投石车26基础伤害，对攻城器额外20，溅射半径2.7。
完整实时数值、模型和动作可在主菜单的战争图鉴查看；生产按钮与训练队列显示当前费用和人口。
工程兵、牧师、重型火炮、三管短炮仍在后续逐单位验收计划中，本版尚未加入。

操作：左键选择，拖框多选，右键移动或攻击；Shift追加命令。生产和建造快捷键以按钮角标为准。
中键拖动、方向键或屏幕边缘平移；滚轮缩放；空格定位选中对象。
B选大本营，F2或G选全部己方战斗单位，句点选空闲农民。F1查看完整操作说明。
F5打开战场菜单；F11全屏；M静音；F10隐藏界面；F12仅单机增加100金币。
设置入口在主菜单或战场菜单，可调整显示、声音、镜头及热键。

建议使用独立显卡。Forward+ Vulkan 渲染，30TPS模拟与显示插值；大量单位仍会增加CPU和GPU负担。
遇到异常：双击 COLLECT_DIAGNOSTICS.cmd，在“文档/积木争霸-诊断”生成本地ZIP。
诊断包包含日志、近期相关Windows错误、显卡/系统信息和EXE/PCK版本校验值；不会自动上传。

从源码重新打包：运行 tools/build_windows.ps1。脚本自动生成内容清单、导出并验证包内地图及数值后才生成ZIP。
直接使用编辑器导出时，先运行 python tools/build_content_manifest.py；兵种或地图变化后需要同步发布relay。
