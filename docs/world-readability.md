# 战场辨识与障碍修正

本轮保留暖色石木、45°正交视角与原有角色动作，修正地面噪声、障碍空气墙和观察者阵营辨识。

## 特效

特效池原先在重置时对尘土、碎屑和火花全部调用 `restart()`，随后才关闭 `emitting`。关闭发射不等于清除已生成粒子，移动标记也可能带出无关碎块。现在重置只停止、隐藏发射器，当前事件仅重新启动需要的发射器；发射数量也恢复明确默认值，避免倒塌后的实例让后续炮口喷出过量烟尘。

普通移动完全移除每个单位的持续行军尘土节点。保留短暂的命中、炮口、爆炸与倒塌反馈，命令落点只显示清晰圆环和箭头。128 实例的原生特效池上限保持不变。

## 碰撞与导航

岩石原先采用手写矩形碰撞，四角存在明显不可见占地。离线生成器现从可见模型的三块主体岩石生成 `ConvexPolygonShape3D`，装饰碎石不阻路；树木改用匹配树干的 `CylinderShape3D`，不以树冠阻挡地面单位。矿脉同样使用实际主体凸包。

物理碰撞和静态导航都读取同一份离线足迹。导航保留 1.15 世界单位的攻城器通行间距，动态建筑占地与一米导航源网格契约保持一致。矿脉在地图两侧连同碰撞、采集位置一起旋转 180°，确保对称。

两张地图中，岩石凸包比旧矩形减少约 45.7% 的无视觉占地，树干圆柱减少约 43%。这项比例描述碰撞投影，不能当作实际地图通行面积增幅。六个采集位置、出生区与两侧道路的原生物理查询及导航连通均通过。

## 观察者配色与建筑

`FactionPalette` 仅负责显示：每个客户端自己蓝色、同盟黄色、敌人红色；`owner_id`、`alliance_id`、攻击过滤和网络权威归属保持独立。单位布料、建筑旗帜和涂色屋顶、世界血条、选择圈、小地图与模型预览使用同一关系映射。

建筑使用明确的建模材质标记存储染色区域，通过原生实例 shader 参数着色，无需每栋复制材质。石材、木材与金属保留原色。建筑轮廓分别为双塔大本营、平顶雉堞兵营、低屋面与高炉烟囱的军工厂、带圆顶书塔的学院、顶置重弩防御塔，外墙扩大了可识别的悬旗区域。

生成命令：`python tools/build_skirmish_maps.py`，随后运行 `Godot --headless --path . --script res://tests/skirmish_maps_bake.gd`。最终使用保存的原生场景和网格资源，对局中不生成几何或碰撞形状。此命令是两张遭遇战地图及其建筑模型的最终生成步骤。

## 验证

- `effect_pool_test.gd`：42 项通过，包括从倒塌特效复用为移动标记时不出现旧尘土或碎屑。
- `skirmish_maps_test.gd`：106 项通过，包括两图对称、原生路径和所有矿脉六个位置的物理通行。
- `world_readability_test.gd`：1727 项通过，覆盖四位观察者的所有阵营关系、五类建筑与六类单位、染色面与石木保色、地图碰撞来源及原矩形空气墙角落的真实物理查询。
- Vulkan 实际渲染五类建筑的蓝、黄、红三组截图，并在正常开局连续放置八个移动标记检查地面干净；日志无脚本或 shader 错误。

原生能力参考：[凸包碰撞](https://docs.godotengine.org/en/4.6/classes/class_convexpolygonshape3d.html)、[实例 shader 参数](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/shading_language.html#per-instance-uniforms)。
