# 0.7.5：剑士对骑兵附伤提高至 20

2026-09-10；Godot 4.6.3 / Windows x64，网络协议版本仍为 4。客户端与上海中继同时更新至 0.7.5，所有联机玩家需使用新版游戏包。

剑士对骑兵的类别附伤从 +6 提高至 **+20**。基础攻击仍为 20，骑士近战护甲为 2，因此无科技每次有效命中造成 **38** 点伤害。满血骑士的剩余生命依次为 **82、44、6、0**，第四刀击杀。双方攻击和防御科技同级时，这一关系保持不变。

剑士费用仍为 45 金币，生命 100，近甲 2、远甲 1，训练 6 秒。弓箭手没有骑兵附伤，保持基础攻击 12。防御塔维持本轮已确认的 **175 金币／20 秒**；其他攻城器、骑士特攻和农民扩容科技沿用 [0.7.4](release-0.7.4.md)。
