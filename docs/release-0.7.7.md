# 0.7.7：投石车重创剑士和弓箭手

2026-09-10；Godot 4.6.3 / Windows x64，协议版本 4。客户端和上海中继均更新为 0.7.7，联机玩家需使用相同版本。

投石车基础攻击仍为 35，新增对剑士类别 +45、对弓箭手类别 +15，保留对建筑 +50。无科技时，中心命中的实际伤害如下：

| 目标 | 实际伤害 | 满血命中一次后剩余生命 |
|---|---:|---:|
| 剑士 | 35 + 45 − 1 = **79** | **21／100** |
| 弓箭手 | 35 + 15 = **50** | **10／60** |
| 骑士 | 31 | 89／120 |
| 投石车 | 31 | 129／160 |
| 加农炮 | 29 | 171／200 |

类别附伤仅匹配目标自己的类别，不叠加不同类别。建筑中心伤害仍为 75；35 基础攻击、200 金币、160 生命、13 射程与 3 秒攻击间隔均不变。

爆炸仍是半径 3、中心半径 1.2 完整伤害、外围衰减至 50%。基础攻击、攻击科技和类别附伤一起衰减，再扣目标当前远程护甲与防御科技。无科技最外围剑士受 39 点、弓手受 25 点伤害。“一发打残”针对中心命中，单位仍可移动躲开固定落点，友军不受伤。

本版包含前一阶段的剑士对骑兵 **+40** 附伤，以及防御塔 **150 金币／1000 生命**，详细规则见 [0.7.6](release-0.7.6.md)。

## 交付和验证

先交付最终 Windows 包，再运行数值矩阵、原生攻击和地图投石落点验证。测试覆盖同一块巨石将剑士打至 21 血、弓手打至 10 血，四名玩家的两类目标、建筑、工地、攻城器、外围衰减、移动躲避、友军过滤，以及发射者阵亡后的在途弹丸。

最终 EXE 通过 116 项发布验证，包括 44 个资源、57 项数值断言、DTLS 加密连接与临时房间流程，错误列表及 stderr 为空。上海发布 `f585b325b1c54812` 正常运行；UDP 24571 的协议、资源清单与脚本逐字节匹配本地，原 UDP 24570 服务保持不变。

原生检查通过：伤害矩阵 1022、实际战斗 52、四玩家真实投石落点 248，共 1322 项。包含 64 项新增的附伤衰减与攻防组合检查，以及 112 个落点样本；三组退出码均为 0，stderr 为空，无引擎错误。

各项原生测试结果及最终包哈希见 [验收记录](validation-0.7.7.json)。本轮临时文件在结果归档后清理，测试进程核实退出；保留最终游戏包、用户编辑器和正式中继。未新增性能或胜率结论；上一阶段已记录的陈旧经济输入夹具不在本次投石车验收范围内。
