# 积木争霸 CPU 实验版

实验版本号：`0.11.1-cpu-exp.1`。此分支用于验证约 500 个单位同时在场时的 CPU 开销、移动响应和模型表现，不替换正式发行版。

目前源码已合入正式 `0.11.0.3` 的拥挤交战修复。共享路径、静态移动证书、站定避让裁剪及替代显示模型仍默认关闭；小规模正确性通过不等于 500 人帧率达标。正式版可从仓库首页下载，用户正在运行的正式包和 Relay 保持不变。

## 运行和反馈

解压后运行同目录下的 `积木争霸.exe`，保留相邻的 PCK 文件。设置保存在独立的 `JimuZhengbaCpuExperiment` 用户目录，第一次启动需要重新设置分辨率、热键和音量。正式版仍可从原来的目录运行。

重点观察多人混编部队集中交战、全军改向、绕建筑、追击、连续 Shift 指令，以及镜头移出再移回时的模型和攻击动作。报告卡顿时请附上场上大致人数、地图、镜头位置、是否担任房主、显示设置和复现步骤。平均 FPS 不能反映所有卡顿，因此实验报告同时记录帧耗时分位数和命令响应。

本轮不会修改或重启公网 Relay，也不会复制实验文件到正式 `builds/windows` 目录。网络协议与数值资源未改；本地同步回归不等于已完成公网多人长时间验证。

## 独立构建

使用 Godot 4.6.3 和对应 Windows 导出模板，在此实验分支中导出 `Windows Desktop`。预设目标目录为 `builds/windows-cpu-experiment-0.11.1`。不要用正式版构建脚本的默认输出目录打包本实验。

原始单位建模场景保留在 `assets/models/units`。骨骼候选位于 `assets/models/units/skinned`，已修复远距离简化网格丢失，仍待重新测量；批量零件候选位于 `assets/models/units/batched`，引用原始网格和阴影网格。两者的适用条件、生成方式和限制分别记录在各自 README 中。

性能条件、通过的检查、未采纳的候选和限制见 `report/cpu-500-experiment-2026-09-10.md`。
