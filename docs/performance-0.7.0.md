## 限帧夹具修正与统计含义

原性能夹具在 `SceneTree._initialize()` 中设置无限帧率，但新增的 `GameSettings._ready()` 会随后恢复用户设置。本次实际观测启动恢复为 **120 FPS 上限、VSync 开启**。夹具现在等待主场景启动完成后，仅对本次测试进程设置 **FPS 上限 0、VSync 关闭**，并在每阶段开始／结束时核实。没有保存或修改用户设置，也没有改变发布版默认值。

显示帧统计使用真实 `process_frame` 墙钟间隔。`physics_logic_ms` 使用保存场景中的前后优先级标记包围 SceneTree 物理回调；它不包括 SceneTree 外部的 PhysicsServer／RVO 求解，也没有把约 33.33 毫秒的逻辑帧间隔当作执行耗时。原始及精简 JSON 另记录 Godot 的 `TIME_PHYSICS_PROCESS` 与 `TIME_NAVIGATION_PROCESS` 缓存监测指标：三个阶段的引擎物理监测 P95 分别为 12.851、21.965、20.032 毫秒，不能与上述 SceneTree 逻辑统计直接相加。

本轮 **39 项夹具检查通过**，标准错误日志为空，采样到的孤立节点数始终为 0。运行器已清理自己的控制台与游戏进程，并通过 CIM 核实退出；清理后仅保留用户原有 Godot 编辑器。
