# 弓箭手输出与骑兵侦察调整

本次只调整两个基础值：弓箭手基础攻击从14降至12，对骑兵的固定附伤仍为+12；骑士视野从12提高至15，弓手视野保持13。生命、护甲、射程、攻速、价格、人口和训练时间均沿用现行数据。

弓手的通用攻击基数降低约14.3%，保留反骑兵附伤，使大量弓手面对有远程护甲的剑士时更需要其他兵种配合。骑士提前发现敌军的距离增加，便于侦察、选择进攻方向与迂回，仍须靠近后才能攻击。

| 满血、无科技的关系 | 单次有效伤害 | 击杀次数 |
| --- | ---: | ---: |
| 弓手 → 骑士 | 12 + 12 − 2 = 22 | 6箭（原5箭） |
| 弓手 → 剑士 | 12 − 4 = 8 | 13箭（原10箭） |
| 骑士 → 弓手 | 19 + 3 = 22 | 3次 |
| 骑士 → 剑士 | 19 − 2 = 17 | 6次 |
| 剑士 → 骑士 | 20 + 6 − 2 = 24 | 5次 |
| 剑士 → 弓手 | 20 | 3次 |

厚甲建筑受到的弓箭伤害也从4降至2，拆除建筑更依赖攻城器。护甲是固定减伤，因此不能把攻击基数的降幅直接当作所有目标上的伤害降幅。科技仍按现有+1/+2/+4总加成计算，双方同级攻防互相抵消；实际交战还受到齐射、走位和接敌距离影响。

真实迷雾以2米格更新。在双方都位于格子中心、间隔14米的测试中，骑士可以发现弓手，弓手尚看不到骑士；骑士的盟友共享该视野。骑士撤离或死亡后，敌军重新隐藏，已探索地形保留。15米视野不改变骑士的1.2米近战射程。
