# RTS 遭遇战实施记录

本轮按已批准的遭遇战、四玩家、战争迷雾与 Host 权威联网方案分阶段交付。

## 阶段一：统一战斗数据

- 单位、建筑、科技是 `data/` 中独立的 Godot Resource；生产、HUD 与战斗共用 `BalanceCatalog`。
- 近战与远程护甲分别计算。类别加成只匹配一个战斗类别，攻防科技 I/II/III 总加成为 1/2/4。
- 发射时保存攻击快照，命中时读取目标护甲；攻击者死亡不使已发射弹丸失效。
- 骑士移除额外冲锋伤害；投石固定落点、中心至外圈衰减；炮弹跟踪单体并仅伤害这一目标。
- 玩家状态区分资产所有者和同盟，科技分别持有；单位为后续联机预留权威模拟边界。
- 矿脉有六个原生 Marker3D 工作点，活动任务占位，停止、死亡和销毁释放，未来排队任务不占位。

验证：`balance_matrix_test.gd` 932 项数值断言、`balance_combat_test.gd` 31 项真实物理/单位/弹丸断言通过；主场景启动与完整退出检查通过，日志无错误。

这一阶段保留原地图与原招募入口；下一阶段迁移到通用建筑生产、训练队列与研究面板。

## 阶段二：生产、建造与科技

- 每座建筑保存原生 `Production` 子节点。大本营仅训练农民，兵营即时生产剑士、弓手与骑士，军工厂即时生产投石与炮。
- 农民训练十秒并预留十人上限；取消全额退款，出口堵塞时保留完成状态。军事人口独立上限六十，无法出场时不扣金币。
- 学院支持逐级研究、同玩家项目去重、不同学院并行不同路线、取消退款和被毁损失当前项目。科技作用于既有及未来军事单位。
- 农民建造菜单使用真实建筑模型。保存了玩家兵营、军工厂、学院模型与独立预览视口；建造费用、时间、尺寸统一取自数据资源。
- 人类、Bot 与未来远端请求通过同一命令队列，物理步执行所有权、费用、人口、前置和坐标校验；重复序号不执行第二次。

验证：真实主场景 `production_rules_test.gd` 37 项检查通过，覆盖训练/人口、取消、科技生效、学院摧毁、同盟所有权和重复命令；完整启动退出日志干净。

## 阶段三：遭遇战、地图与战争迷雾

- 新增 96×96 的琥珀十字路与 128×112 的双谷争锋；默认 1v1 对 Bot，四人模式按 owner 独立持有金币、单位、人口及科技。
- 每人以 320 金币、三名自动采矿农民和大本营开局。移除免费敌军增援与拆楼金币奖励。
- 每联盟共享三态视野；隐藏敌军不参与选取、计数、小地图、音效与特效显示。建筑记忆冻结在最后一次发现时，无实时生命值或碰撞体。
- Bot 使用相同经济/命令入口、已侦察情报和小队策略；清除全部军事建筑及工地决定胜负，失去全部已完工核心生产建筑后永久暴露该队剩余及未来建筑。
- 地图采用少量合并静态网格与预制导航格，施工时只修改变化占地；大图寻路显式限制 16384 多边形，避免默认 4096 限制截断跨图路径。

验证：地图107项、迷雾273项、Bot策略107项、两图边界各37项通过。两图分别进行六分钟无注资真实AI对战，首伤约45.5秒/40.8秒，军工、学院、科技均能发展，经济/人口/矿位/施工不变量持续通过。真实Vulkan场景截图、完整退出无错误。
