# 积木争霸 0.11.0.3

此正式热修基于 `322cfcf55e0236c5b24f70e6346ed3f4e90895db` 的拥挤交战修复，保留已有多人个人击杀结算与联机断线修复。

- 攻击、坚守和工作中的单位站稳后由移动部队绕行，重新移动时恢复正常避让速度。
- 取消兵种间不一致的避让优先级，减少后排与大型单位持续挤动前排。
- 待命和攻击移动中的单位可以切换到已在射程内的敌人，减少拥挤时持续追逐旧目标导致的停攻；明确攻击命令和正在进行的前摇不被自动改令。

网络协议仍为 10，兼容 BUILD_ID 仍为 `0.11.0`，数值和地图内容指纹不变。建议所有人更新；拥挤交战修复由新版房主执行。Relay 是否需要部署以实际协议、指纹与服务器状态核对为准，不因展示版本号变化而重启活跃房间。

原交战补丁在独立干净源码上通过 152 项拥挤检查、466 项追击／攻击时序检查及 124 项多人复制检查，详见 [交战修复说明](crowd-contact-combat.md)。发布包的实际启动和联机核查另在发行记录中归档。

CPU、共享路径、静态运动缓存和骨骼模型实验继续保留在独立工作树，本正式包不启用未验证获益的候选。旧版发行附件保留供回退。
