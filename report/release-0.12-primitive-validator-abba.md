# 中继 primitive 校验：单次字典遍历候选未采用

当前中继对每个快照只进行一次有界解压、UTF-8 转换、JSON 解析和 primitive 校验，随后直接转发原始 packet；它没有再次 stringify、压缩或深复制快照。`NetworkProtocol._primitive` 的字典分支依次检查 key、调用 `values()` 创建临时数组、校验子值，因此提出单次 key/value 遍历候选，避免每个字典的 `values()` 分配。

候选保留原有深度 12、65,536 值预算、有限浮点数、key 长度 64、字符串长度 32,768 及非法类型拒绝规则，标量检查仍在循环内。**实际结果更慢，未修改或替换产品中的 `NetworkProtocol`。**

全新 headless 夹具使用与当时中继版本一致的 **Godot 4.7.2 官方编辑器运行时**，加载生产主场景，生成 500 个实际六类单位并取得完整快照。快照包括 516 个实体，JSON 为 118,802 字节；正式有界编解码往返一致。关闭场景后，单独对解析后的相同数据做两轮 ABBA，每段 64 次，共 512 次纯校验。正常用户编辑器保留；不把本测试解释为对局 FPS、公网吞吐或 Linux CPU 的直接测量。

| 轮次 | 原版 A1 | 候选 B1 | 候选 B2 | 原版 A2 |
|---|---:|---:|---:|---:|
| 1 | 7.741 ms | 8.069 ms | 8.201 ms | 7.763 ms |
| 2 | 7.776 ms | 8.171 ms | 8.230 ms | 7.813 ms |

原版平均 **7.773 ms**，候选 **8.168 ms**，约慢 **5.1%**。各段结果方向一致。减少临时数组没有产生净收益；候选增加的逐键取值等操作尚未单独计时，不能进一步断言是哪一种原生操作造成退步。

恶意输入和边界差分共 **5,568 项断言全部通过**，包含 2,500 棵固定种子随机嵌套树、深度与值数量上下界、非法 key、超长字符串、NaN/Infinity、Object 与非 JSON 容器。所有输入的接受/拒绝结果一致；接受数据的剩余值预算也必须相同。拒绝数据的提前退出顺序可以不同，其剩余预算不被调用方使用。

本次结果支持保留现有校验，不跳过安全检查。它也提供一个量级参考：在这台 Windows 机器与该运行时上，单是每秒 38 份同形状快照的校验已对应约 0.30 秒单线程时间，尚未计入 JSON 解析、DTLS 与其它消息；实际 Linux 中继仍应测量。辅助 PID 29868 已退出，命令核实仅用户编辑器 36624 存在。配套 JSON 保存原始分段数据、源码与夹具摘要；没有部署变化。
