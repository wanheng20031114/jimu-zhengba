# 灰烬王国 · 原创声音

全部文件由 `tools/build_audio.py` 离线合成，没有使用外部录音、音效库或借用旋律。格式统一为 **48 kHz、单声道、PCM16 WAV**。包含短首尾 fade，不削波；原始技术检查数据见 `audio_manifest.json`。

| cannon.wav | 2.35 s | 低沉压力爆发、低频尾响和近反射 |
| stone_hit.wav | 1.15 s | 重石落地及不规则碎砾弹跳 |

战斗声音预留约 3–8 dB 峰值余量，UI 预留约 11–14 dB。多人同屏时建议世界音效再衰减约 7–12 dB，并使用空间衰减、同种碰撞限频和有限复音数；避免每个士兵每次接触都叠加为满音量。

环境轨第一和最后采样均为零，长尾采用循环回绕。循环播放由 Godot AudioStreamWAV 的循环设置控制。音乐为可选轨，风声可独立使用。

验证范围：11 个 WAV 的采样格式、时长、峰值、RMS、频谱能量、高频占比、零首尾及无削波均已检查通过。当前工具没有音频试听分析能力，未通过系统音箱播放。重新生成可执行 `python tools/build_audio.py`。
